# English Listening Lab

一个适合手机和电脑使用的双语英语精听学习站。

- 音频与字幕精准同步
- 中英对照、英式音标、词重音和意群提示
- 深色 / 浅色主题
- 按月份和中英文主题筛选
- 新概念英语 1–4 册逐句点读与语法标注
- 纯静态页面，由 GitHub Pages 托管

## 新概念英语（`/nce/`）

第 1 册到第 4 册共 348 课，入口是 <https://youngcpp.github.io/english-listening-lab/nce/目录.html>（站点首页也有专区卡片）。

- **多彩标注**：主语、谓语、宾语、表语、定语、状语、各类从句和时态按句子成分上色，由依存句法分析（spaCy）自动生成；判不准的成分宁可空着。
- **逐句点读**：点任意一句，音频直接跳到那句的起点并在句尾停下。时间轴不用原版字幕，而是用本机逐词转写（Whisper）重新对轴——这批录音的字幕本身越往后越漂，最多差 13.6 秒，不重对轴就会点 A 句听到 B 句。
- **音频**：276 段课文朗读，AAC（m4a）64 kbps 单声道，从原盘 MP3 转码而来。第 1 册偶数课原书只配练习、没有整段朗读，因此只有标注。
- **离线可用**：`nce/` 整个文件夹拷到任何地方，用浏览器打开 `nce/目录.html` 即可，页面与音频都是相对路径，不依赖网络。
